Notes

  • rustc = g++
  • cargo is for conveniently building projects
    -cargo new makes a new project
    -cargo check for code validity
    -cargo build to build debuggable version into target/debug/projectname
    -cargo build --release to build release (no-debug and optimized) version into target/release/projectname
    -Cargo.lock and Cargo.toml should BOTH be in git version control. Cargo.lock caches version at time of first pull
    -cargo update ignores and recomputes Cargo.lock and associated versions
    -cargo doc --open builds documentation locally and opens a browser with associated documentation.
  • Rust works off Option and Result
    -Result<T> can be of enum T with the correct value, or as enum Error
    -Option<T> can be of enum T with the correct value, or as enum None
